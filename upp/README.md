u++ (Ukrainian Plus Plus)
==========================

Невелика експериментальна мова програмування з українським синтаксисом.

Цей файл описує **синтаксис і семантику мови**, а також спосіб запуску програм.

---

## 1. Концепція мови

U++ — це проста інтерпретована мова, орієнтована на читабельний український синтаксис:

- змінні оголошуються через конструкцію `нехай ... буде ...`;
- вивід — через `показати`;
- умовні вирази — `якщо` / `інакше`;
- цикли — `поки`;
- вирази будуються з чисел, рядків, булевих значень і змінних;
- підтримуються базові арифметичні та порівняльні операції українськими словами.

---

## 2. Лексика

### 2.1. Коментарі

- Коментар починається з символу `#` і триває до кінця рядка:

```text
# це коментар
нехай а буде 10  # це теж коментар після коду
```

### 2.2. Числа

- Цілі десяткові числа:

```text
нехай а буде 10
нехай б буде 0
```

### 2.3. Рядки

- Рядкові літерали беруться у подвійні лапки:

```text
нехай привітання буде "Привіт, світе!"
показати "Результат: "
```

(escape‑послідовності поки що мінімальні, інтерпретатор читає текст між лапками як є).

### 2.4. Булеві значення

- Літерали:

```text
правда
брехня
```

Приклади:

```text
нехай флаг буде правда
нехай іншийФлаг буде брехня
```

### 2.5. Ідентифікатори

- Імена змінних — послідовність літер/цифр/підкреслення, що **починається з літери або `_`**:

```text
нехай а буде 10
нехай змінна_2 буде 5
```

## 3. Оператори та вирази

Усі оператори записуються **словами українською**:

- арифметика:
  - `додати` — додавання
  - `відняти` — віднімання
  - `помножити` — множення
  - `поділити` — ділення (цілочисельне; при діленні на нуль кидається помилка)
- порівняння:
  - `більше` — `>`
  - `менше` — `<`
  - `дорівнює` — `==`
 - логічні:
   - `і` — логічне «і» (AND)
   - `або` — логічне «або» (OR)
   - `не` — логічне заперечення (NOT)

### 3.1. Приклади виразів

```text
нехай сума буде 10 додати 5
нехай різниця буде 10 відняти 3
нехай добуток буде 2 помножити 4
нехай частка буде 10 поділити 2

нехай більшеЧиМеньше буде 10 більше 3
нехай дорівнюєЧиНі буде 5 дорівнює 5
```

Вирази можуть вкладатися один в один:

```text
нехай результат буде 10 додати 5 помножити 2
```

## 4. Інструкції (Statements)

### 4.1. Оголошення змінних

Синтаксис:

```text
нехай <імʼя> буде <вираз>
```

Приклад:

```text
нехай а буде 10
нехай б буде а додати 5
```

### 4.2. Вивід (print)

Синтаксис:

```text
показати <вираз>
```

Приклад:

```text
показати "Результат:"
показати а
```

### 4.3. Умовний оператор `якщо` / `інакше`

Базовий варіант:

```text
якщо <умова> то
    <інструкція‑або‑блок>
```

З гілкою `інакше`:

```text
якщо <умова> то
    <інструкція‑або‑блок>
інакше то
    <інструкція‑або‑блок>
```

Приклад:

```text
нехай а буде 10
нехай б буде 5

якщо а більше б то
    показати "a більше"
інакше то
    показати "b більше"
```

Умова — будь‑який вираз, який приводиться до `bool` у Python (ненульові/непорожні значення вважаються `правда`).

### 4.4. Цикл `поки`

Синтаксис:

```text
поки <умова> то
    <інструкція‑або‑блок>
```

Інтерпретатор виконує тіло циклу, поки умова лишається істинною.

Приклад лічильника:

```text
нехай i буде 0

поки i менше 5 то
    нехай i буде i додати 1

показати i  # 5
```

> Тіло `якщо/поки` — це блок інструкцій, який задається відступом після рядка з `то` (Python‑подібно).

## 5. Приклади програм

### 5.1. Проста арифметика

```text
нехай а буде 10
нехай б буде 5
нехай с буде а відняти б
показати с
```

Вивід:

```text
5
```

### 5.2. Умови

```text
нехай вік буде 18

якщо вік більше 17
показати "Повнолітній"
інакше
показати "Неповнолітній"
```

### 5.3. Цикл `поки`

```text
нехай лічильник буде 0

поки лічильник менше 3
нехай лічильник буде лічильник додати 1

показати "Лічильник дорівнює"
показати лічильник
```

## 6. Запуск програм

### 6.1. Запуск через встановлений пакет

Після встановлення (`pip install -e .` у корені проєкту) доступна консольна команда:

```bash
uplusplus run program.upp
```

### 6.2. Запуск напряму через модуль

Без встановлення пакета:

```bash
python -m uplusplus.main run program.upp
```

### 6.3. Запуск з кореня проєкту (інтеграція з VS Code)

У корені `Upp1` є обгортка `main.py`, яка викликає CLI:

```bash
python main.py program.upp
```

Цю команду використовує розширення VS Code (**Run U++**) у вбудованому терміналі.

## 7. Помилки

- Лексичні (`LexerError`): невідомі символи, незакриті рядки.
- Синтаксичні (`ParseError`): неочікувані токени, помилки у структурі інструкцій.
- Рантайм (`RuntimeErrorUPlusPlus`):
  - використання невідомої змінної;
  - ділення на нуль;
  - невідомі операції/інструкції (на випадок розширень).

Усі помилки виводяться українською мовою у стандартний потік помилок.
