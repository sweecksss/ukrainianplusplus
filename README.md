# U++ (Ukrainian Plus Plus)

Невелика мова програмування з українським синтаксисом. Інтерпретатор
написано на C без залежностей.

```text
функція привітати(імʼя)
    показати "Привіт, {імʼя}!"

нехай друзі буде ["Оксана", "Тарас", "Леся"]
нехай і буде 0

поки і менше довжина(друзі) то
    привітати(друзі[і])
    і стає і додати 1
```

## 1. Швидкий старт

Запуск програми:

```bash
upp програма.upp
```

Або через обгортку, якщо бінарник лежить у теці проєкту:

```bash
python main.py програма.upp
```

Готові приклади — у теці [`examples/`](examples).

Інтерпретатор повертає **0**, якщо програма відпрацювала без помилок, і
**1**, якщо сталася будь-яка помилка — лексична, синтаксична або під час
виконання. Це дозволяє використовувати U++ у скриптах і CI.

## 2. Лексика

### Коментарі

Від `#` до кінця рядка:

```text
# це коментар
нехай а буде 10  # і це теж
```

### Числа

Цілі та дробові:

```text
нехай ціле буде 42
нехай дробове буде 3.14
нехай відʼємне буде -7
```

### Рядки

У подвійних лапках. Підтримуються екрановані послідовності
`\n`, `\t`, `\r`, `\"`, `\\`, `\{`, `\}`:

```text
показати "Перший рядок\nДругий рядок"
показати "Він сказав: \"привіт\""
```

Усередині рядка можна підставити значення змінної через фігурні дужки:

```text
нехай імʼя буде "світ"
показати "Привіт, {імʼя}!"     # Привіт, світ!
показати "Дужки: \{не змінна\}" # Дужки: {не змінна}
```

У підстановку можна писати **лише назву змінної**, не цілий вираз.

### Назви

Починаються з літери або `_`, далі — літери, цифри, `_`. Українські
літери — повноцінні літери:

```text
нехай кількість_студентів буде 25
нехай ціна2 буде 10.5
```

### Відступи

Тіло блоку задається відступом, як у Python. Табуляція рахується за
4 пробіли. Вихід на рівень, якого немає серед відкритих блоків, — помилка.

Короткий блок можна писати в один рядок після `то`:

```text
якщо вік не менше 18 то показати "Повнолітній"
```

## 3. Типи значень

| Тип | Приклад | Примітки |
|---|---|---|
| число | `42`, `-7` | ціле, 64 біти |
| дробове число | `3.14`, `2.0` | подвійна точність |
| булеве значення | `правда`, `брехня` | |
| рядок | `"текст"` | незмінний, UTF-8 |
| список | `[1, 2, 3]` | посилальний тип |
| функція | `функція ф() ...` | |
| ніщо | — | результат функції без `повернути` |

**Істинність.** У логічному контексті хибними вважаються: `брехня`,
`0`, `0.0`, порожній рядок, порожній список, `ніщо`. Усе інше — істина.

**Списки — посилальний тип.** Присвоєння списку не копіює його:

```text
нехай а буде [1, 2]
нехай б буде а
додати_до(б, 3)
показати а            # [1, 2, 3]
```

## 4. Вирази та операції

Операції записуються словами.

### Арифметика

| Операція | Значення |
|---|---|
| `додати` | додавання; для рядків — склеювання; для списків — обʼєднання |
| `відняти` | віднімання |
| `помножити` | множення |
| `поділити` | ділення |
| `-` | унарний мінус |

**Ділення.** Якщо обидва операнди цілі — результат цілий, дробова
частина відкидається. Якщо хоч один дробовий — результат дробовий:

```text
показати 7 поділити 2      # 3
показати 7.0 поділити 2    # 3.5
```

Ділення на нуль — помилка виконання.

### Порівняння

| Операція | Значення |
|---|---|
| `більше` | `>` |
| `менше` | `<` |
| `дорівнює` | `==` |
| `не дорівнює` | `!=` |
| `не менше` | `>=` |
| `не більше` | `<=` |

Порівнювати можна числа між собою (ціле з дробовим — теж) і рядки з
рядками. Рядки порівнюються за порядком байтів.

### Логічні операції

| Операція | Значення |
|---|---|
| `і` (або `та`) | AND, з коротким замиканням |
| `або` | OR, з коротким замиканням |
| `не` | заперечення |

Коротке замикання означає, що права частина не обчислюється, якщо
результат уже відомий.

> **`і` як назва змінної.** `і` — і сполучник, і найзвичніша назва
> лічильника. Оскільки в U++ два вирази ніколи не стоять поруч, позиція
> в тексті однозначно каже, що мається на увазі, тож `нехай і буде 0` і
> `а і б` працюють обидва. Якщо хочеться однозначності — є синонім `та`.

### Пріоритет

Від найнижчого до найвищого:

1. `або`
2. `і` / `та`
3. `не`
4. порівняння
5. `додати`, `відняти`
6. `помножити`, `поділити`
7. унарний `-`
8. індексація `[...]`, виклик `(...)`

Дужки змінюють порядок:

```text
показати 2 додати 3 помножити 4      # 14
показати (2 додати 3) помножити 4    # 20
```

Заперечення стоїть вище за порівняння, тому
`не а дорівнює б` читається як `не (а дорівнює б)`.

### Списки

```text
нехай числа буде [1, 2, 3]
показати числа[0]           # 1
числа[1] стає 99            # [1, 99, 3]
показати довжина(числа)     # 3
показати [1, 2] додати [3]  # [1, 2, 3]
```

Індекси починаються з нуля; вихід за межі — помилка виконання.
Рядки теж індексуються, **у символах, а не в байтах**:

```text
нехай слово буде "привіт"
показати довжина(слово)     # 6
показати слово[3]           # в
```

## 5. Інструкції

### Оголошення змінної

```text
нехай <назва> буде <вираз>
```

### Присвоєння

```text
<назва> стає <вираз>
<назва>[<індекс>] стає <вираз>
```

`нехай` **створює** змінну в поточній області видимості, `стає` —
**змінює наявну**. Присвоєння неоголошеній змінній є помилкою: так
одразу видно одруківку в назві.

```text
нехай лічильник буде 0
лічильник стає лічильник додати 1
```

### Вивід

```text
показати <вираз>
```

### Умова

```text
якщо <умова> то
    <блок>
інакше то
    <блок>
```

Слово `то` необовʼязкове. Гілку `інакше` можна пропустити. Ланцюжок
умов будується вкладеним `якщо` в гілці `інакше`.

### Цикл

```text
поки <умова> то
    <блок>
```

## 6. Функції

```text
функція <назва>(<параметри>) то
    <блок>
```

```text
функція площа(ширина, висота)
    повернути ширина помножити висота

показати площа(3, 4)     # 12
```

- `повернути <вираз>` повертає значення; `повернути` без виразу
  завершує функцію зі значенням `ніщо`.
- Функція без `повернути` теж дає `ніщо`.
- Функції видно з будь-якого місця файлу, зокрема **до** їхнього
  оголошення — тому взаємна рекурсія працює.
- Тіло функції бачить свої параметри, власні локальні змінні та
  глобальні змінні, але **не** локальні змінні того, хто її викликав.
- Глибина рекурсії обмежена 200 викликами: інакше нескінченна рекурсія
  клала б увесь процес без пояснень.

Блоки `якщо` та `поки` **не** створюють окремої області видимості —
власну область має лише виклик функції.

## 7. Вбудовані функції

| Функція | Опис |
|---|---|
| `довжина(х)` | довжина рядка в символах або кількість елементів списку |
| `ввести()` | читає рядок з клавіатури |
| `ввести(підказка)` | те саме, але спершу друкує підказку |
| `число(х)` | перетворює рядок або булеве значення на число |
| `текст(х)` | перетворює будь-що на рядок |
| `додати_до(список, значення)` | додає елемент у кінець списку |

```text
нехай вік буде число(ввести("Скільки тобі років? "))
нехай наступний буде вік додати 1
показати "Через рік буде {наступний}"
```

Власна функція з такою самою назвою має перевагу над вбудованою.

## 8. Помилки

Усі повідомлення — українською, у стандартний потік помилок, із номером
рядка (а для лексичних і синтаксичних — і з колонкою).

- **Лексичні** — невідомий символ, незавершений рядок, неузгоджений
  відступ, некоректне число.
- **Синтаксичні** — порушення структури інструкцій.
- **Помилки виконання** — невідома змінна чи функція, ділення на нуль,
  індекс поза межами, невідповідність типів, неправильна кількість
  аргументів, перевищення глибини рекурсії.

Якщо в програмі є лексичні або синтаксичні помилки, вона **не
виконується взагалі** — інтерпретатор показує всі знайдені проблеми
одразу й завершується з кодом 1.

## 9. Складання та тести

### Windows (MSVC)

```bash
upp-c\build.bat
```

Скрипт сам знаходить Visual Studio через `vswhere`.

### Linux / macOS

```bash
make -C upp-c
```

Складання із санітайзерами памʼяті:

```bash
make -C upp-c debug
```

### Тести

Набір золотих тестів лежить у [`tests/`](tests): кожна програма
`NNN-назва.upp` має файл `NNN-назва.expected` з очікуваним виводом,
повідомленнями про помилки та кодом виходу.

```bash
python tests/run_tests.py
```

Корисні прапорці:

```bash
python tests/run_tests.py 012          # лише тести з «012» у назві
python tests/run_tests.py --exe шлях   # інший бінарник
python tests/run_tests.py --update     # перезаписати очікувані результати
```

### Структура репозиторію

```text
upp-c/        інтерпретатор мови (C11) — єдина реалізація
tests/        золоті тести
examples/     приклади програм
installer/    інсталятор для Windows
tools/        допоміжні скрипти складання
upp-vscode-extension/  розширення для VS Code
docs/         опублікований сайт (копія кореня)
downloads/    файли, які роздає сайт
```

Сторінка сайту лежить у корені (`index.html`, `style.css`, `app.js`), а
`docs/` — її точна копія, щоб GitHub Pages працював за будь-якого
налаштування. Після зміни сайту виконайте синхронізацію:

```bash
python tools/sync_site.py          # скопіювати корінь -> docs/
python tools/sync_site.py --check  # перевірити, чи не розʼїхались
```

Перезбирання інсталятора та розширення:

```bash
upp-c\build.bat              # спершу інтерпретатор
installer\build_setup.bat    # інсталятор (сам вшиває свіжий upp.exe)
python tools/build_vsix.py   # розширення для VS Code
```
