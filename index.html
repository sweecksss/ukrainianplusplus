Швидкий старт

Щоб виконати файл з кодом U++, завантажте upp.exe і виконайте у терміналі:

upp.exe program.upp

Приклад першої програми:

нехай імʼя буде "Олексій"
показати "Привіт, {імʼя}!"

Змінні та типи даних

Оголошення змінної виконується конструкцією нехай <імʼя> буде <вираз>.

Типи даних:

  • Числа: 10, -5, 100
  • Рядки: "Текст" (підтримують інтерполяцію "{змінна}")
  • Булеві значення: правда, брехня
нехай вік буде 20
нехай активний буде правда
нехай повідомлення буде "Вік: {вік}"
показати повідомлення

Математичні та логічні оператори

Операція Ключове слово Приклад

Умовні оператори (якщо / інакше)

    показати "Відмінно!"

    нехай лічильник буде лічильник додати 1
    показати "Крок номер: {лічильник}"

Як безкоштовно захостити цей сайт?

3 найпростіших способи опублікувати сайт в мережі абсолютно безкоштовно

Найпопулярніший

1. GitHub Pages (Рекомендовано)

Безкоштовний хостинг прямо з вашого репозиторію GitHub із власною адресою yourname.github.io/upp.

  1. Створіть безкоштовний акаунт на GitHub.com.
  2. Створіть репозиторій з назвою upp-site.
  3. Завантажте всі файли з папки site/ у цей репозиторій.
  4. Перейдіть у Settings ➔ Pages, оберіть гілку main і натисніть Save.
  5. Через 1-2 хвилини ваш сайт буде доступний для всього світу!

2. Vercel

Супер-швидкий хостинг з миттєвим деплоєм за 1 клік.

  1. Зареєструйтесь на Vercel.com.
  2. Натисніть Add New ➔ Project.
  3. Імпортуйте свій репозиторій з GitHub або перетягніть папку site/.
  4. Отримайте безкоштовний домен upp.vercel.app та безкоштовний SSL-сертифікат.

3. Netlify

Простий варіант без використання командного рядка (Drag & Drop).

  1. Зареєструйтесь на Netlify.com.
  2. Перейдіть у раздел Sites.
  3. Просто перетягніть папку site/ у вікно браузера!
  4. Сайт запрацює миттєво за адресою upp.netlify.app.
