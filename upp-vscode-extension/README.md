## U++ (Ukrainian Plus Plus) — поддержка в VS Code

Расширение добавляет поддержку экспериментального языка программирования **U++ (Ukrainian Plus Plus)** в Visual Studio Code.

U++ — это простой язык с украинскими ключевыми словами. Пример кода:

```text
нехай а буде 10
нехай б буде 5

якщо а більше б
показати "а більше"
інакше
показати "б більше"
# це коментар
```

### Возможности

- **Распознавание файлов**: `.upp`
- **ID языка**: `upp`
- **Подсветка синтаксиса**:
  - ключевые слова: `нехай`, `буде`, `показати`, `якщо`, `інакше`
  - операторы: `додати`, `відняти`, `помножити`, `поділити`, `більше`, `менше`, `дорівнює`
  - булевы литералы: `правда`, `брехня`
  - строки `"..."`, числа, комментарии `# ...`
- **Автодополнение и сниппеты**:
  - предложенные ключевые слова: `нехай`, `буде`, `показати`, `якщо`, `інакше`, `правда`, `брехня`
  - сниппеты:
    - объявление переменной: `нехай ${1:імя} буде ${2:значення}`
    - `якщо`‑блок
    - `якщо` / `інакше`‑блок
- **Скобки и отступы**:
  - автодополнение скобок и кавычек
  - отступ при переходе на новую строку после `якщо` или `інакше`
- **Иконка файлов**:
  - отдельная иконка для файлов `.upp` (включается через тему иконок расширения).

### Запуск программ U++ из VS Code

Расширение добавляет команду **"Run U++"**, которая запускает текущий `.upp`‑файл через интерпретатор U++.

Предполагается, что интерпретатор запускается командой:

```text
python main.py <файл>
```

и файл `main.py` находится в корне рабочей папки, где лежит ваш `.upp`‑файл.

**Как пользоваться:**

- Откройте `.upp`‑файл в редакторе.
- Нажмите кнопку **Run U++** в правом верхнем углу редактора (иконка в заголовке файла), либо:
  - откройте **Command Palette** (`Ctrl+Shift+P`),
  - введите `Run U++` и выполните эту команду.
- Встроенный терминал VS Code откроется (или переиспользует терминал **"U++ Run"**), перейдёт в папку проекта и выполнит:

```text
python main.py <ваш-файл.upp>
```

Вывод программы будет показан в этом терминале.

### Установка из исходников

1. Откройте в VS Code папку `upp-vscode-extension` из каталога вашего проекта `Upp1`.
2. Нажмите `F5`, чтобы запустить окно **Extension Development Host**.
3. В новом окне создайте или откройте файл с расширением `.upp` — подсветка, автодополнение и сниппеты будут работать автоматически.

### Включение иконки для `.upp` файлов

1. В окне **Extension Development Host** откройте `Settings` → `File Icon Theme`.
2. Выберите тему **"U++ Icons"**.
3. В проводнике VS Code файлы `.upp` будут показываться с иконкой U++.
