## U++ (Ukrainian Plus Plus) — підтримка у VS Code

Розширення додає підтримку мови програмування **U++ (Ukrainian Plus Plus)**
у Visual Studio Code.

U++ — проста мова з українськими ключовими словами:

```text
функція привітати(імʼя)
    показати "Привіт, {імʼя}!"

нехай друзі буде ["Оксана", "Тарас"]
нехай і буде 0

поки і менше довжина(друзі) то
    привітати(друзі[і])
    і стає і додати 1
```

### Можливості

- **Розпізнавання файлів:** `.upp`, ID мови — `upp`
- **Підсвічування синтаксису:**
  - оголошення: `нехай`, `буде`, `стає`, `показати`
  - керування: `якщо`, `інакше`, `поки`, `то`, `функція`, `повернути`
  - арифметика: `додати`, `відняти`, `помножити`, `поділити`
  - порівняння: `більше`, `менше`, `дорівнює`, `не дорівнює`, `не менше`, `не більше`
  - логіка: `і`, `та`, `або`, `не`
  - вбудовані функції: `довжина`, `ввести`, `число`, `текст`, `додати_до`
  - рядки з екрануванням і підстановкою `{змінна}`, числа, коментарі `# ...`
- **Автодоповнення** ключових слів, операцій і вбудованих функцій
- **Сніпети:** оголошення змінної, `якщо`, `якщо`/`інакше`, `поки`,
  цикл-лічильник, обхід списку, оголошення функції, створення списку,
  читання з клавіатури
- **Дужки та відступи:** автозакриття дужок і лапок, відступ після `то`
- **Іконка файлів** `.upp` (через тему іконок розширення)

### Запуск програм із VS Code

Розширення додає команду **«Run U++»**, яка запускає поточний `.upp`-файл.

Інтерпретатор шукається у такому порядку:

1. `upp-c/upp.exe` (або `upp-c/upp`) у теці проєкту — свіжозібраний бінарник;
2. `upp.exe` (або `upp`) у корені теки проєкту;
3. `upp` із `PATH` — саме туди його додає інсталятор.

**Як користуватися:**

- Відкрийте `.upp`-файл.
- Натисніть **Run U++** у правому верхньому куті редактора, або
  викличте `Ctrl+Shift+P` → `Run U++`.
- Вивід зʼявиться у вбудованому терміналі **«U++ Run»**.

Якщо програма завершиться з помилкою, інтерпретатор поверне код 1 і
покаже українською, що саме сталося і в якому рядку.

### Встановлення з початкових кодів

1. Відкрийте у VS Code теку `upp-vscode-extension`.
2. Натисніть `F5` — відкриється вікно **Extension Development Host**.
3. У новому вікні створіть або відкрийте файл `.upp`.

### Іконка для файлів `.upp`

`Settings` → `File Icon Theme` → **«U++ Icons»**.
